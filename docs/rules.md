# 雀魂半庄规则与奖励（项目训练设定）

更新：2026-11-10。用户确认四位扣分固定按 −165，无需再询问段位。

- 目标：四人半庄战、玉之间，起始 25,000 点，赤宝牌 3 张，有食断、后付。
- 训练/对战环境默认 `game_length=8`；南4 后未达到结束条件时西入，最多至西4。亲家连庄、终局和被飞条件由已打补丁的 libriichi 执行。
- 段位分训练奖励：
  `房间顺位马 + 顺位得点(+15/+5/−5/−15) + (终局点数−25000)/1000`。
- 半庄房间顺位马固定为 **+110/+55/0/−165**。因此四位的顺位部分合计为 −180，再叠加素点；不要将 −165 误作完整奖励。
- 东风兼容配置保留 +55/+30/0/−80，不用于本次目标训练。
- 终局未领取供托归一位；索引原始结算与 GRP 的终局点数比较时要统一这项处理。
- SL 的 value 标签为完整最终段位分 /100；delta 标签为本局点数变化 /10000。

## 规则近似与验收范围

RL 引擎仍包含部分天凤规则处理，例如双倍役满、包牌及三家和等细节与雀魂的差异。正式强化学习前应审核这些差异和测试覆盖。

SL 使用真实牌谱及预处理后的标签。缺失结算的牌谱需要估算最后一局，估算不包含所有隐藏宝牌信息；回放通过不等同于精确还原真实终局点数。

评估中的 `pt_placement` 只有顺位部分；完整指标使用 `mean_pt`，包括终局素点。重复牌山的 4 次座位轮换归为一个 seed 统计单元。

RL 回报（2026-11-10 原训练负责人复核后定稿）：默认 `return_mode=grp`，即 GRP 按局奖励 r_k = φ(s_{k+1}) − φ(s_k)，φ = GRP 预测的期望顺位分 + 素点/1000（/100 缩放），使用 `ckpt/grp_hanchan.pth`（kind=hanchan，rounds=12）。各局奖励求和等于完整终局段位分减初始 φ，在 GRP 校准良好时与终局回报同目标、方差更低。`return_mode=terminal`（完整终局段位分 /100）保留为可选对照。
